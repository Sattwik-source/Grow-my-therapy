# Dr. Maya Reynolds - Therapist Website

A modern, responsive website for Dr. Maya Reynolds, a licensed clinical psychologist specializing in anxiety, trauma, and burnout therapy in Santa Monica, CA.

## Features

- **Modern Design**: Clean, professional aesthetic with a calming color palette
- **Fully Responsive**: Works seamlessly on desktop, tablet, and mobile devices
- **Smooth Animations**: Scroll-triggered animations and hover effects
- **SEO Optimized**: Proper meta tags and semantic HTML structure
- **Accessible**: WCAG-compliant design patterns

## File Structure

```
assigment/
├── index.html       # Main HTML file
├── styles.css       # All CSS styles

```

## Technologies Used

- **HTML5**: Semantic markup
- **CSS3**: Modern styling with CSS variables, flexbox, and grid
- **Vanilla JavaScript**: Smooth scrolling, scroll animations, and navigation highlights

## Customization

### Update Contact Information
Edit the phone number in `index.html`:
```html
<a href="tel:+1-000-000-0000" class="cta-button-white">Schedule a Consultation</a>
```

### Change Colors
Modify CSS variables in `styles.css`:
```css
:root {
    --primary: #2d5a6b;
    --accent: #c9a961;
    --light-bg: #f8f7f5;
}
```

### Add Images
Create an `images/` folder and update the HTML to include `<img>` tags where needed.
